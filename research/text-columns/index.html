Text columns: the prompts for every dataset

For each MulTaBench image dataset: a link to the dataset, what its target is, the exact sentences used as prompts, and its result.

How the text columns are made
  1. One short sentence per class (for a numeric target: five sentences describing ordered levels, low to high).
  2. Each image and each sentence are embedded with BiomedCLIP and with dino.txt (both frozen).
  3. Column value = 100 × cosine similarity between the image and the sentence. One column per sentence per model.
  4. The columns are added to the table; everything else is MulTaBench's released pipeline (TabPFN-v2, frozen DINOv3-small + PCA 30, their splits). No labels and no training are used to make the columns.

Prompts were written once on 2026-10-04 from each dataset's metadata (target name and class values), before any result on these datasets, and never changed. Development datasets were used to select the two image–text models; untouched ones were never looked at before this run, so only they test the claim.
